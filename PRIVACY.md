# Privacy

- Search terms, selected prefecture, and type filters stay in the browser.
- Saved entries contain only public local-government codes and are limited to eight records in local storage.
- Telemetry stores only an allowlisted event name, a one-way session hash, an automated-QA flag, and a timestamp.
- Search terms, selected organizations, codes, contact data, advertising identifiers, and authentication data are not collected.
- Telemetry is deleted after 35 days by a scheduled Worker task.
- Automated browser sessions are separated from human user metrics.
