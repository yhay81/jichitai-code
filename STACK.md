# Stack

- Cloudflare Workers and custom domain routing
- Hono with JSX for the public HTML surface
- Vite+ for check, test, build, and local development
- Static verified JSON for client-side search
- Cloudflare D1 for minimal anonymous event telemetry
- Plain browser JavaScript and CSS, with no account system

Better Auth is intentionally absent because all useful state is local and no cross-device or private data workflow exists.
